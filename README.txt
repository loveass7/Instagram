PREMIUM LINK VAULT

Files:
- index.html
- style.css
- script.js
- images/ (put your 10 images here)

Default login:
Username: admin
Password: 1234

To change login:
Open script.js and edit LOGIN_USERNAME and LOGIN_PASSWORD.

To add your links:
Open index.html and replace each https://example.com/... with your real URL.

To add your images:
Put your 10 images inside the images folder and name them:
link1.jpg
link2.jpg
...
link10.jpg

You can also change the image filenames in index.html.

IMPORTANT:
The login in this version is client-side JavaScript protection. It is suitable for a personal/static GitHub Pages-style site, but it is NOT strong server-side security. Anyone who can inspect the site's files can discover the credentials.
